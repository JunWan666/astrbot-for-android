# 更新记录

## 未发布

- 后台运行引导增加系统检测状态和手动确认记录，返回设置后自动刷新；每项详情集中为一个主要操作按钮，支持按品牌直达设置与备用入口。自启动权限引导不等于 App 会在开机后自动启动服务。
- 运行环境准备空间改为预估提醒，首次初始化、启动及环境升级或修复时可选择“仍然继续”；已初始化环境的日常启动不受此预估限制。实际读写失败仍会报错并清理未完成的环境暂存文件。
- 应用增加“跟随系统 / 简体中文 / English”语言设置，覆盖界面、通知、后台引导及管理器提示；人设正文和上游日志保留原内容。
- 运行扩展增加按需安装的 cpolar 客户端，支持内嵌官方 WebUI 登录与隧道管理、独立启停、实时日志与卸载；登录后由官方页面自动保存令牌，默认提供 SSH、AstrBot、NapCat 三个隧道，客户端按需下载。
- cpolar 默认隧道读取创建时各服务的实际端口；保留已有账号和自建隧道，后续修改或删除预设不会被重置。
- cpolar 后台默认使用 75% 缩放，支持固定比例切换与外部浏览器访问；后台就绪状态独立检测，日志支持实时跟随、暂停、复制和导出。
- 沿用 v1.0.0 的应用包名和长期签名，支持保留数据覆盖升级；AstrBot、NapCat 与运行环境版本保持兼容。

## v1.0.0

- 运行通知使用应用 Logo，并提供适配状态栏的单色图标，修复仍显示 Android 默认图标的问题。
- 首页普通布局和紧凑布局统一在右侧显示运行服务数量，启动过程中持续更新 `0/2`、`1/2`、`2/2`。
- 提供包含 PRoot Ubuntu、AstrBot 和 NapCat 的完整 Android 安装包。
- 支持环境初始化、双服务启停、连接状态、内置 WebUI 和局域网访问。
- WebUI 默认 75% 缩放，支持固定比例切换与有效初始凭据填写。
- 内置离线人设库，支持搜索、预览、添加、默认切换和恢复。
- 人设库支持自建和删除，内置预设也可删除；提供玖帕喵人设市场的外部浏览器入口。
- 提供实时日志、资源统计、SSH 扩展及手机后台设置引导。
- 支持本机快照、便携备份、更新回退和自动快照容量管理。
- 接入 GitHub 签名更新通道，管理器、AstrBot 与 NapCat 分别检查更新；NapCat 使用上游正式程序包，保留配置和 QQ 会话。
- 提供中英文 README 切换，以及复用本地长期签名、带中文提示的一键正式构建脚本。
