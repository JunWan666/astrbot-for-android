# 更新记录

## 未发布

### 新增

- 底部新增“网页”：添加、编辑和删除常用 HTTP / HTTPS 地址，自动获取网站图标，在应用内浏览并为各地址保存缩放比例；默认提供 DeepSeek 用量页。
- 设置一级新增“权限”：接入可选的 Shizuku，随包提供未修改的官方离线安装包，由用户安装、启动并授权。支持检测后台派生子进程的配置值、有效上限、本应用与全机已跟踪数量，手动调整上限或恢复默认，并管理本应用的息屏省电白名单。
- 扩展新增按需安装的 DeepSeek Harness，独立准备 Node.js 和固定版本依赖，提供启停、日志、内嵌工作台及可选的局域网访问；默认不安装，不预填模型凭据，卸载程序保留工作目录与配置。
- 新增默认关闭的 Android 设备访问：Ubuntu 工具可查询设备与本 App 状态，分别授权后可读取界面、截图、点击、滑动及输入。通过私有本地连接提供固定操作，锁屏时暂停读屏及控制；Shizuku 提供设备操作，可选无障碍服务补充界面读取与中文输入。
- 新增 `/android-share` 文件交换目录及系统文件导入、导出入口，方便 Android 与 Ubuntu 交换文件。

### 优化与修复

- 首页服务在后台探测确认就绪后才显示“运行中”并计入数量；从准备、排队到执行结束持续显示忙碌状态，减少重复点击和状态提前结束。
- 设置、扩展和权限采用统一的分类菜单与卡片，连续显示，小屏或大字号可滚动；权限详细说明按需展开，检测结果标注时间，无法读取时显示未知。
- 桌面依赖及原版 QQ 下载显示已下载大小、总大小、百分比与速度，下载阶段支持暂停、继续和停止；Harness 安装显示六个阶段、耗时、最近输出及实际依赖活动，补齐下载计数，并提供局域网 IP 与认证访问入口。
- 改善 Ubuntu 桌面与 Linux QQ 的进程管理：记录进程归属，异常退出后回收残留进程，减少重启时端口被占用的问题；重新打开 App 时检查桌面原启用状态。
- 统一终端选区手柄、放大镜与复制的字符边界，修复拖动选区时多选、少选问题，补齐中文及其他双宽字符处理。
- 终端退出 137、143 时补充诊断提示，管理器日志记录会话启停、退出码与息屏省电状态，不记录终端命令或输出。
- 管理器更新弹窗增加外部浏览器下载选项，保留内置下载、自动校验、快照与安装流程。

### 发行与兼容

- 正式打包从当前源码重新编译原生进程及终端托管程序，核对源码、编译结果与 APK 摘要，修复旧预编译缓存可能漏带会话生命周期修复的问题。
- 补齐 Shizuku、DeepSeek Harness 的固定版本、下载摘要、依赖锁及第三方许可材料，同步中英文 README、使用指南和构建说明。
- Shizuku 与设备访问均由用户主动开启；系统限制的调整以回读结果为准，不保证绕过厂商后台清理或内存回收。Ubuntu 的 root 仍是 PRoot 模拟身份，不获得其他 App 的私有数据访问权限。

## v1.2.0

管理器版本 `1.2.0`，版本代码 `10023`，沿用正式包名与长期签名，支持保留数据覆盖升级。

- 补齐 Ubuntu 对 App 自有目录的路径映射，使进程通过 `/proc` 获取的 Android 文件路径也能正确读取，修复全新环境中 Linux QQ 扩展组件无法完成初始化的问题。
- 内存统计跳过已释放地址空间的退出进程，修复桌面残留进程导致首页长期显示“部分统计”且应用占比为空的问题；仍保留真实读取失败时的部分统计提示。
- 后台运行页增加“在最近任务中隐藏”开关，保存选择并支持恢复任务卡片，桌面图标仍可进入；页面改为紧凑单页，小屏幕可上下滑动。
- 终端方向键按上方“↑”、下方“← ↓ →”排列，Tab 移至左下角；首排末尾改为“粘贴”，第二排末尾改为“回车”。首次默认字号调整为最小值 10，保留已有字号设置。Android 9 及以上在长按选字、拖动选区时显示原生放大镜，松手收起。
- 修复关闭管理器更新页时，清理 TLS 连接可能在主线程触发异常的问题。
- 完善 Linux QQ 与 Ubuntu 的运行兼容性：为受限内核提供匿名动态库加载和可访问 POSIX 锁记录的读取兼容，增加可选的主线程动态库初始化配置；工具独立实现，不携带外部程序或其组件，默认不配置额外动态库。
- 管理器更新统一为“检查更新 → 查看新版说明并下载 → 自动校验 → 系统安装”，未授予安装权限时引导授权，返回后继续；当前无适用新版时弹出明确提示，保留下载续传与安装前数据快照。
- AstrBot 与 NapCat 的凭据页新增重置功能：生成新的随机后台凭据，仅恢复对应服务的原运行状态，保留业务与 QQ 登录数据；AstrBot 同步更新密码摘要并撤销旧登录会话，首次登录要求改密。
- 终端触摸滚动保留像素偏移并按显示帧合并移动，缓存手势期间的布局尺寸，改善逐行跳动；保留惯性、长按选字、返回最新输出和独立会话。
- Ubuntu 桌面扩展提供 GCC、G++、make、Python 和 curl，简化手动程序的编译与安装；独立原版 QQ 更新为腾讯官方 3.2.34-53644，旧版显示更新入口，替换程序前完成校验并保留登录数据，安装失败可恢复旧程序，并支持重试被系统终止的替换；启动时设置独立的标准通信目录，避免 PRoot 与 Android 用户编号差异造成路径不一致。
- 完善 Ubuntu 初始化校验失败提示，在诊断日志中记录资源路径、读取字节数及期望/实际摘要；正式 APK 导出前增加包内完整运行环境校验，并将结果写入构建记录。
- 修复 Android 工作线程结束时，仍在运行的终端、桌面等受托管会话可能被提前停止的问题；改为检查 App 父进程是否退出，保留主动停止和父进程退出后的清理机制。
- 修复部分 Android 内核缺少子进程列表接口时，结束会话可能遗留脱离进程组的后代的问题；备用清理仅处理当前托管器拥有且尚未回收的子进程。
- 调整独立桌面 QQ 的 Electron 启动参数，将 GPU 工作保留在主进程并避开受限共享内存路径，改善 Android/PRoot 下 GPU 子进程不可用导致的退出。

## v1.1.0

### 新增

- 中英文界面：支持跟随系统、简体中文与 English，覆盖管理界面、通知、后台引导和操作提示；人设正文、用户数据与上游日志保留原语言。
- cpolar 扩展：按需安装官方客户端，通过内嵌 WebUI 登录并管理隧道，无需单独复制 token；默认提供 SSH、AstrBot、NapCat 三个隧道，按创建时的实际端口配置，保留已有账号与自建隧道。
- Ubuntu 终端：无需 SSH 即可使用本机交互 Shell，支持多个独立会话、标签切换和返回后后台运行；关闭单个会话不影响其他会话，环境维护前统一关闭。
- Ubuntu 桌面：按需安装轻量图形环境，通过内嵌 noVNC 访问，支持启停、密码管理和实时日志；可单独安装腾讯原版 ARM64 QQ，数据独立保存，并与 NapCat 管理的 QQ 进程互斥运行。
- 精选人设：内置吃白饭的大肥鱼、月见八千代、DeepSeek娘，以及根据精选拟人模板补全的小满。展示发布者、原帖链接和改编说明，排除破甲内容，补齐中文短句、句末标点与真实换行规范。

### 优化与修复

- 后台运行引导增加系统检测状态和手动确认记录，返回设置后自动刷新；每项详情集中为一个主要操作按钮，支持按品牌直达设置与备用入口。自启动权限引导不等于 App 会在开机后自动启动服务。
- 存储空间不足预估改为提醒，可选择“仍然继续”初始化、启动或准备环境升级；已初始化环境的日常启动不再被此预估拦截。实际读写失败仍会报错并清理未完成的环境暂存文件。
- 终端增加长按选取、拖动手柄复制和惯性滚动，查看历史时不跳回最新输出；选区操作使用紧凑按钮，字号加减紧邻键盘入口，底部快捷键固定两排并提供直接粘贴入口。
- 扩展组件改为带间距的独立卡片，Ubuntu 桌面位于终端下方；修复 cpolar 内嵌后台返回时陷入网页历史、无法退出到扩展详情的问题。cpolar 保留默认 75% 缩放及固定比例切换。
- 默认 OneBot 地址改为 `ws://127.0.0.1:6199/ws`，避免 localhost 的 IPv6 解析差异；启动前备份并迁移仍保持原始默认参数的旧连接，保留自定义端口、token、目标及停用状态。
- 针对 NapCat 4.18.41 / Linux QQ 3.2.34-53644 在 ARM64 PRoot 下的反检测 Worker 崩溃，启动前备份配置并关闭六项不兼容选项，保留 O3、QQ 会话及业务配置；环境检查提供说明，兼容调整仅记录日志。此处理不保证解决所有 QQ 掉线或账号风控问题。
- 人设页在进入页面与 AstrBot 后台就绪时刷新导入状态，修复首次启动完成后仍提示先启动、按钮保持禁用的问题；预览说明分段开关和长回复阈值，保留自建人设、删除记录及已导入的副本。

### 发行与兼容

- 正式 APK 启用并校验 v1、v2、v3 签名，改善部分系统安装器的签名识别兼容性；沿用 v1.0.0 包名与长期证书，支持保留数据覆盖升级。
- 管理器版本为 `1.1.0`，版本代码为 `10012`。随包组件保持 AstrBot `4.29.3`、NapCat `4.18.41` 与 Linux QQ `3.2.34-53644`；AstrBot、NapCat 继续独立检查更新。
- 同步中英文 README、人设截图、使用指南和第三方来源声明；源码仓库保留必要代码、构建工具、锁文件与公开文档，开发产物和个人排障资料在本地管理。
